# 联机模式测试指南

## 🎯 完成状态

联机模式已完全集成！现在支持：

- ✅ 单人模式（AI敌人）
- ✅ 联机模式（玩家控制的敌人）
- ✅ 狙击手角色（第一人称）
- ✅ 敌人角色（第三人称 + WASD控制）
- ✅ 实时位置同步
- ✅ 射击同步
- ✅ 击中检测和伤害系统
- ✅ 分数同步
- ✅ 游戏结束处理

## 🚀 快速开始

### 1. 启动服务器

```bash
cd threejs-version/server
npm install  # 首次运行需要安装依赖
npm start    # 或使用 npm run dev（开发模式）
```

服务器将在 `http://localhost:3000` 运行（默认端口）。

**自定义端口**：如果需要修改端口，请参考 [端口配置指南](./PORT_CONFIGURATION.md)。

### 2. 打开游戏

在浏览器中访问：`http://localhost:3000`（或你配置的端口）

## 🎮 测试流程

### 单人模式测试

1. 点击 "单人模式"
2. 使用右键/Shift开启瞄准镜
3. 左键/空格射击AI敌人
4. 尝试在60秒内获得高分

### 联机模式测试（本地多标签页）

#### 标签页1 - 狙击手（房主）
1. 点击 "联机模式"
2. 输入玩家名称（例如："狙击手"）
3. 点击 "创建房间"
4. 记下房间ID
5. **等待至少1名敌人玩家加入**
6. 当玩家数量 ≥ 2 时，点击 "开始游戏"

#### 标签页2-4 - 敌人玩家
1. 点击 "联机模式"
2. 输入玩家名称（例如："敌人1"、"敌人2"）
3. 点击 "加入房间"
4. 从列表中选择房间（或输入房间ID）
5. 等待房主开始游戏

#### 游戏中
- **狙击手视角**：
  - 鼠标移动瞄准
  - 右键/Shift切换瞄准镜
  - 左键/空格射击
  - 尝试在60秒内击杀所有敌人玩家（每人3条命）

- **敌人视角**：
  - **W** - 向前移动
  - **S** - 向后移动
  - **A** - 向左移动
  - **D** - 向右移动
  - 第三人称相机会跟随你的角色
  - 躲避狙击手的射击，存活60秒

## 🔍 预期行为

### 狙击手端
- 能看到所有敌人玩家（绿色/蓝色模型）
- 敌人玩家移动时实时更新位置
- 射击击中敌人时：
  - 敌人闪红
  - 分数增加
  - 敌人生命值减少
- 敌人玩家死亡时会倒下并淡出

### 敌人端
- 第三人称视角跟随自己的角色
- WASD移动流畅
- 被击中时：
  - 角色闪红
  - 显示伤害效果
  - 生命值减少
- 死亡时角色倒下

### 通用
- 60秒时间到或所有敌人死亡时游戏结束
- 显示最终分数
- 房主离开时所有玩家返回主菜单

## 🐛 可能遇到的问题

### 问题1：服务器无法启动
**解决方案**：确保端口3000未被占用
```bash
# Windows
netstat -ano | findstr :3000

# macOS/Linux
lsof -i :3000
```

### 问题2：无法连接到服务器
**解决方案**：
- 确保服务器正在运行（控制台显示 "Server running on port 3000"）
- 检查浏览器控制台是否有错误
- 尝试刷新页面

### 问题3：房间列表为空
**解决方案**：房间列表功能尚未实现，请直接使用 "创建房间" 和手动输入房间ID加入

### 问题4：移动卡顿
**原因**：每帧发送位置更新可能在高延迟网络下造成卡顿
**解决方案**：这是已知问题，后续会优化更新频率

### 问题5：第三人称相机不跟随
**解决方案**：
- 确保你是敌人角色（不是狙击手）
- 检查浏览器控制台是否有错误
- 尝试重新加入房间

## 📊 技术细节

### 网络架构
- 使用 Socket.io 进行实时通信
- 房间系统支持多个独立游戏
- 每个房间最多4名玩家（1狙击手 + 3敌人）

### 同步机制
- **位置同步**：敌人每帧发送位置更新
- **射击同步**：狙击手射击时立即发送事件
- **伤害同步**：服务器权威，确保公平性

### 角色系统
- **狙击手**：第一人称，Player类
- **敌人**：第三人称，PlayerEnemy类
- 本地玩家：绿色模型
- 远程玩家：蓝色模型
